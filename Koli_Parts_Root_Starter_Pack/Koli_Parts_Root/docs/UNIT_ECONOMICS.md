# Unit Economics

## Formula

`Customer gross price - VAT/accounting effect - supplier landed cost - payment fee - fulfillment cost - expected return reserve - expected fraud/support allocation = contribution margin`

## Example model (illustrative only)

Do not use these as production prices; replace with supplier/accountant data.

| Customer price | Supplier + inbound | Payment/ops | Return reserve | Illustrative contribution |
|---:|---:|---:|---:|---:|
| €25 | €18 | €1.0 | €1.0 | €5.0 before VAT/accounting treatment |
| €50 | €38 | €1.6 | €2.0 | €8.4 before VAT/accounting treatment |
| €100 | €78 | €2.8 | €4.0 | €15.2 before VAT/accounting treatment |
| €250 | €205 | €6.0 | €10.0 | €29.0 before VAT/accounting treatment |
| €500 | €420 | €11.0 | €20.0 | €49.0 before VAT/accounting treatment |

A flat 6% margin is not automatically viable. Category-specific landed cost, return probability and support burden matter.

## Required model inputs
- actual supplier discount/price,
- shipping DE/domestic/forwarding/BG,
- payment fees,
- VAT treatment,
- return shipping,
- seller failure rate,
- wrong-fit rate,
- damage/loss rate,
- support cost/order,
- acquisition cost.
