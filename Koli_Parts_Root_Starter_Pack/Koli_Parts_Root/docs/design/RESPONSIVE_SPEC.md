# Responsive Spec

Source breakpoints aligned with Koli One: 375, 414, 768, 1024, 1280, 1920.

Test viewports at minimum: 360, 375, 390, 414, 430, 768, 1024, 1280, 1440, 1920.

## Mobile
- touch targets >=44px,
- vehicle context compact/sticky where useful,
- filters in drawer/sheet,
- single-column product cards,
- sticky checkout CTA only when it does not cover critical warnings.

## Desktop
- dense but readable filter/search layout,
- use available width for fitment/offer comparison,
- product detail can use gallery + purchase column.

No hover-only critical action. No desktop layout that merely stretches mobile cards.
