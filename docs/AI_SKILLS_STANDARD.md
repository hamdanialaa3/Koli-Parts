# Koli Parts AI Skills Standard

These five capabilities are the default engineering workflow standard for AI-assisted development in this repository.

## 1. Find Skills
Use SKILL.md-based discovery to locate reusable skills before reinventing workflows. Verify source quality and inspect instructions before adoption.

## 2. Superpowers
Repository: https://github.com/obra/superpowers.git

Use explicit planning, test-driven development where applicable, implementation checkpoints, code review, and verification before considering work complete. Avoid unstructured vibe coding.

## 3. Claude Mem
Repository: https://github.com/thedotmack/claude-mem

Use persistent project context so architectural decisions, constraints, conventions, recurring defects, and project state survive across Claude Code sessions.

## 4. Impeccable
Use for frontend and product UI work. Enforce systematic spacing, typography, hierarchy, responsive behavior, accessibility, visual consistency, and anti-AI-slop review.

## 5. Task Observer
Inspect repeated corrections, workflow bottlenecks, recurring defects, and manual patterns. Convert stable patterns into improved skills, tests, automation, checklists, or project instructions.

## Operating rule
For meaningful engineering tasks, apply these capabilities together when relevant: discover reusable skills first, plan before coding, test and verify changes, preserve project context, apply rigorous UI standards, and improve the workflow from observed repetition.

Local Claude Code / VS Code installation still requires developer-environment setup on each workstation.
