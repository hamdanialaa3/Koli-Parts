# Analytics & KPIs

## Funnel
`landing → search → vehicle selected → product viewed → fitment reviewed → cart → checkout → payment authorized → procurement confirmed → shipped → delivered`

## Core events
- `search_submitted`
- `vehicle_selected`
- `vin_added`
- `product_viewed`
- `fitment_warning_seen`
- `add_to_cart`
- `checkout_started`
- `payment_authorized`
- `order_created`
- `procurement_reviewed`
- `procurement_failed`
- `shipment_created`
- `return_requested`
- `refund_completed`

## KPIs
- Search-to-product CTR
- Add-to-cart rate
- Checkout conversion
- Procurement success rate
- Supplier stock mismatch rate
- Supplier price-change rate
- Wrong-fit return rate
- Overall return rate
- Median procurement time
- Median delivery time
- Contribution margin/order
- Refund cycle time
- Repeat purchase rate

Avoid sending raw VIN or unnecessary PII to analytics providers.
