# Accessibility Spec

Target: WCAG 2.2 AA.

- fitment states use icon + label + text, never color alone,
- visible focus ring using semantic focus token,
- complete keyboard operation for search/filter/modal/admin queues,
- form errors bound to fields and announced,
- minimum touch target 44px,
- semantic headings/landmarks,
- alt text policy for product images,
- reduced-motion support,
- contrast tests for both Koli light/dark themes,
- price and delivery updates announced where dynamically changed.
